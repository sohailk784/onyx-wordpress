# Differences from the live site

| Area | Live (React) | WordPress |
|---|---|---|
| Language / currency switcher | Present | Not implemented (consider WPML/Polylang + CURCY) |
| Product carousels & tabbed rails | Animated carousels / tabs | Static WooCommerce product grids |
| Product page | Custom sectioned layout | WooCommerce single product + tabs, styled to match |
| Cart | Card layout + order summary | WooCommerce classic cart table + totals, styled |
| Contact WhatsApp/email cards | Filled cards | Outlined buttons |
| Shop count | 117 products shown | 122 (all published; review which to hide) |
| Wholesale | Trader accounts + pricing | Application form only (see wholesale.md) |
| Payments | Crypto + processor | Offline crypto gateway with proof upload (on-hold orders) |

Header/footer, typography, colours, home, FAQ, contact, calculator, check-code, plans, legal pages and the
age gate match closely; see the side-by-side screenshots delivered with the build.
